# Bonsai 2 prism.3 — Experimental / 实验版

面向 **Ternary Bonsai 2 27B** 的 Windows x64 实验预编译版，包含 Web UI 和 CUDA 运行库，编译支持 **RTX 20 / 30 / 40 / 50 系**。默认关闭 MTP，可按下方步骤自行开启。

## 快速启动（默认关闭 MTP）

安装兼容 CUDA 12.9 的 NVIDIA 驱动及 [Microsoft VC++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。CPU 需支持 AVX2/FMA/F16C/BMI2。运行预编译包无需安装 CUDA Toolkit、Python 或 Node.js。

解压运行包，在其目录打开 PowerShell，将下面的模型路径替换成实际路径：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows\start-bonsai.ps1 -Model 'D:\models\Ternary-Bonsai-2-27B-PTQ1_0.gguf' -Gpu 0
```

启动完成后打开 **http://127.0.0.1:18202/**。终端会显示加载进度及请求的 prefill/decode 速度；保持窗口打开，按 Ctrl+C 停止服务。多显卡机器可修改 `-Gpu`。

| 默认设置 | 值 |
|---|---|
| 上下文上限 | 128K（131072 tokens） |
| KV 检索预算 / 生成预留 | 24K / 10K（24576 / 10240 tokens） |
| 主模型 K / V 缓存 | Q8_0 / Q8_0 |
| 思考预算 | 4096 tokens |
| MTP | 关闭；手动开启时默认 MTP1、草稿 KV F16 |

128K 是上下文上限，24K+10K 是 KV 池预算。显存不足时，可以先在启动命令末尾添加较小配置：

```powershell
-Context 8192 -Budget 2048 -Reserve 1024 -ReasoningBudget 256
```

## 可选：将 MTP 头量化为 Q4_0 并开启

推荐小显存用户先使用默认的无 MTP 模式。想尝试加速时，可将 BF16 MTP 头直接量化为 Q4_0，再合并进主模型。**主模型仍保持 PTQ1，只有新增 MTP 头的矩阵被量化；归一化参数保留 F32。**

### 1. 准备转换环境

下载上面的主模型、MTP 头以及**匹配源码包**。解压源码包，进入同时包含 `scripts` 和 `llama.cpp` 的 `source` 目录。

安装 **Python 3.11 或更高版本**，然后在该目录打开 PowerShell，执行：

```powershell
python -m venv .venv-mtp
.\.venv-mtp\Scripts\python.exe -m pip install numpy PyYAML tqdm
```

脚本会使用源码包内匹配的 `llama.cpp/gguf-py`，无需安装 PyTorch 或单独安装 gguf。

### 2. 量化并合并

假设下载的两个文件都在 `D:\models`，执行：

```powershell
.\.venv-mtp\Scripts\python.exe .\scripts\bonsai-mtp-graft.py `
  --base 'D:\models\Ternary-Bonsai-2-27B-PTQ1_0.gguf' `
  --head 'D:\models\model_mtp.safetensors' `
  --output 'D:\models\Ternary-Bonsai-2-27B-PTQ1_0-MTP-r3-Q4_0.gguf' `
  --head-type Q4_0
```

输出为可直接加载的完整 GGUF（约 **6.19 GB**），另附同名 JSON 转换记录。Q4_0 头比原模型增加约 **228 MiB** 权重，运行时还需额外的草稿 KV 和工作缓冲区。请预留输出文件所需磁盘空间。

脚本会校验输入文件 SHA256，并验证原模型权重未被改变。输出路径必须是新文件；如果提示校验不匹配，请检查是否下载了表中指定版本。无需再对整个模型运行 `llama-quantize`。

如需 Q8_0 头，将 `--head-type` 改为 `Q8_0`，并将输出文件名相应改为 `...-MTP-r3-Q8_0.gguf`；两种量化均从原始 BF16 头转换。

### 3. 使用合并后的模型启动

回到**运行包目录**，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows\start-bonsai.ps1 -Model 'D:\models\Ternary-Bonsai-2-27B-PTQ1_0-MTP-r3-Q4_0.gguf' -Gpu 0 -Mtp
```

这会开启 **MTP1，草稿 KV 为 F16**。要尝试 MTP2，在末尾添加 `-DraftTokens 2`。MTP 的加速效果取决于任务，且会增加显存占用。

**Q4_0 合并模型务必显式传入 `-Model`**：当前启动器在仅指定 `-Mtp` 时会查找默认目录下的 Q8_0 合并模型。原始 PTQ1 文件不含 MTP 头，不能直接开启 MTP。
