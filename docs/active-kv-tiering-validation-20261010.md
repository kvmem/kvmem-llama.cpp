# 活跃 KV 分层验收记录（2026-10-10）

实现位于 `feat/active-kv-tiering`，基于 `eb98424e7654c5bdd054bf9ce46485d09a991f84`。
两个后端共用原生字节、配额、文件 I/O 和有界任务队列，完整 K/V 可下沉到 SSD，
mean-K 留在 RAM。原生历史在活动/闲置之间移动同一份所有权，附件另计且共用 D。
本记录描述已运行的范围；统计区间较宽的项目保留为未资格化，不改写为通过。

## 正确性、失败与并发

- 最终 Windows 公共层 17/17 通过。WSL/GCC 的地址、未定义行为及泄漏检查通过。
- 两后端的原生 K/V、量化附属字节、状态、MTP 和 RAM/SSD token/usage 对照通过。
  llama 覆盖 C1/C2/C4，ninfer 覆盖 C1/C2/C8、RK8V4/MTP3/CUDA Graph。
- 真实 Windows 写盘失败只结束受影响请求；热请求输出与 RAM 一致，后续重试成功。
  阻塞写入期间取消冷请求，热请求仍可再生成 8 个 token。
  阻塞冷读取时其他记录继续分配；失败读取回滚预留并保留有效磁盘副本。
- llama CPU 图像 + 固定 MTP3 + 强制 SSD 通过图像替换、精确输出/usage、真实 I/O、配额和清理。
  ninfer CPU 图像 + 快速预填充 + 自适应 MTP3 + Graph 的十个有效 token 向量完全一致，
  包括旧图像冷恢复、查询图像重放、替换、取消恢复、预算拒绝后的恢复。
  被取消请求的生成长度不用于等值对照；取消后的恢复结果用于对照。
- Launcher、Engine/serving 参数、后端补丁正反向检查与全新本地检出精确 tree 重建通过。
  Windows 包两 worker 在清洁运行时 PATH 下加载成功；此检查只证明依赖完整。

## 实际 SSD 成本

这里测量的是启用文件分层后的端到端成本。实现使用系统缓存文件 I/O，文件读取
计数记录 ReadFile/pread 的逻辑字节；测试未清除文件缓存，也未观测物理 SSD 读取量。
刚写入的数据可能命中系统文件缓存，因此 RAM 层的“冷 KV”不等于物理设备冷读。
H 不限制操作系统文件缓存。真正内存压力/冷文件缓存下的 SSD TTFT 尚需独立验证，
不能把现有百毫秒级差值解释为已验收的物理 SSD 冷读性能。

同一个最终二进制比较充足 RAM 与强制 SSD。C2 的热请求在波次间处于闲置状态；
ninfer 的差值包含闲置 checkpoint 恢复。它不能直接证明一个正在解码的热请求被冷 I/O 阻塞；
阻塞期间的热请求进展由前述确定性测试验证。小样本负差值不解释为 SSD 固有加速。

## 同日后续：合并写入与空闲区间索引

上述 SSD 长上下文结果来自优化前快照，保留为历史测量。后续接入最多 256 KiB
小写入合并，将 llama 的写调用从 96,689 次降到 6,447 次；该次单组对照总耗时
75.939 -> 76.623 秒，未观察到推理加速。

CPU 定向诊断发现 SSD 区间分配从头扫描所有占用记录，连续分配总成本 O(N²)。
96,689 条、每条 17,408 字节时，合并模式分配空间 41.100 秒，打包和写入 0.912 秒。
改为按大小索引空闲区间，并复用 C++17 node_handle 保证释放不申请内存后，同规模
分配耗时降到 0.038 秒；计时外完整读回和配额检查通过。

5060 Ti、0.8B Q8_0、H32/D4096 MiB、260,085 输入 token、128 输出 token，
已启用合并写入的同一基线与空闲索引优化各运行一次：总耗时 140.177 -> 33.383 秒，
prefill 136.998 -> 29.505 秒；精确续聊 4.672 -> 3.928 秒。全部请求的内容、usage
及存储统计完全相同，读写错误为零、配额不越界、退出清理通过。本轮基线明显慢于
上一轮 76.623 秒，波动原因未另行定位；不将单组约 4.2 倍推广为稳定倍率。

此次必要检查为 Windows spill_io_test / tiered_kv_storage_test、Linux spill_io_test
ASan/UBSan，以及上述 CPU 诊断和一组模型对照。新增覆盖分配失败回滚、碎片拒绝、
最小适配、相邻合并及禁止内存申请时释放。两个 Windows 后端均以 8 并行编译成功，
未追加完整测试矩阵。原始证据位于任务根目录的 `ssd-free-index-20261010`，
前一轮写合并记录位于 `ssd-write-batching-integration-20261010`。
